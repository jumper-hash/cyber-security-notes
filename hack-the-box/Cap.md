# HackTheBox Cap Full Chain Penetration Testing

## External Reconnaissance and Web Entry
- Port Enumeration: Executing `nmap -sC -sV cap.htb` and identifying exposed services on ports `21`, `22`, and `80`.
- FTP Enumeration: Identifying `vsftpd 3.0.3` on port `21`.
- CVE Identification: `vsftpd 3.0.3` is affected by `CVE-2021-30047`, which can be used for Denial of Service (DoS).
  - Vulnerability Assessment: The identified CVE only provides a DoS attack path, making it irrelevant for obtaining initial access or privilege escalation on the target.
- Web Entry: Accessing `http://cap.htb/` on port `80` and enumerating application functionality.
  - Request Interception: Using Burp Suite to inspect the download request generated by the Security Snapshot functionality.

## Exploitation and Initial Access
- IDOR Vulnerability: Identifying that the snapshot download endpoint accepts a user-controlled numeric identifier.
- Exploitation: Modifying `/download/1` to `/download/0` to access an older PCAP file not intended to be directly accessible.
- PCAP Analysis: Opening the retrieved capture in Wireshark and inspecting network traffic for exposed credentials.
- Credential Discovery: Recovering FTP credentials for user `nathan` from plaintext traffic.

## SSH Access
- Credential Reuse: Reusing the recovered `nathan` credentials to authenticate through SSH.

```bash
ssh nathan@cap.htb
```

- Initial Access: Establishing a stable shell as `nathan`.

## Local Enumeration
- Process Enumeration: Executing `ps aux` to identify potentially interesting processes; no relevant privilege escalation vector found.
- Network Enumeration: Executing `ss -tulpn` to enumerate listening services; no relevant local service identified.
- Capability Enumeration: Searching the filesystem for Linux capabilities using:

```bash
getcap -r / 2>/dev/null
```

## Privilege Escalation
- Critical Finding: Identifying `CAP_SETUID` assigned to `/usr/bin/python3.8`.

```text
/usr/bin/python3.8 = cap_setuid,cap_net_bind_service+eip
```

- Capability Analysis: `CAP_SETUID` allows the process to change its UID, including setting UID `0` (`root`).
- Exploitation: Using Python's `os.setuid(0)` to change the process UID to root.

## Root Shell
- Payload:

```python
import os

os.setuid(0)

print("`id`:")
os.system("id")

print("`ls -la /root`:")
os.system("ls -la /root")
```

- Execution:

```bash
python3 exploit.py
```

- Privilege Escalation Result: Successfully obtaining UID `0` and access to `/root`.

## Final Exploitation
- Root Access: Confirming successful privilege escalation through `id` / `whoami`.
- Flag Retrieval: Reading the root flag from `/root/root.txt`.
