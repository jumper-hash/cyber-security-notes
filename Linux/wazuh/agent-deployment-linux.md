# Agent deployment
Command generated by Wazuh, used to deploy agent: `wget https://packages.wazuh.com/4.x/apt/pool/main/w/wazuh-agent/wazuh-agent_4.14.5-1_amd64.deb && sudo WAZUH_MANAGER='192.168.10.1' WAZUH_AGENT_GROUP='default' dpkg -i ./wazuh-agent_4.14.5-1_amd64.deb`

## Encountered problems
After installation endpoint was not visible in the panel

## Troubleshooting
- `systemctl status wazuh-agent.service` revealed that service is running
- configuration file inspection
  - `/var/ossec/etc/ossec.conf` had improper server ip address `10.10.15.1`, changing it to `192.168.10.1` fixed problem
- `systemctl restart wazuh-agent.service` restarted service, which led to estabilishing connection with Wazuh server
